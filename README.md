# 《万籁同源》 One Origin of All Sounds

> 世界级原创生成式音乐 · 纯 NumPy 合成 · 零外部依赖 · 作者 **晨星**

一首以**东方五声音阶（宫商角徵羽 = C D E G A）**为内核、五幕递进的原创交响电子作品：

**静谧 → 萌动 → 冲突 → 爆发 → 合一**

全曲由代码生成，可运行、可复现、可验证，无任何外部音频素材或采样。

## 音乐内核

| 幕 | 主题 | BPM | 意象 |
|----|------|-----|------|
| Ⅰ | 静谧 Tranquility | 50 | 低音 drone + 高空 bell，留白与呼吸 |
| Ⅱ | 萌动 Awakening | 72 | 共享动机（宫商角徵）拨弦入场，低音脉冲 |
| Ⅲ | 冲突 Conflict | 100 | 固定音型 + 半音碰撞，小二度不协和渐强 |
| Ⅳ | 爆发 Eruption | 132 | 驱动低音 + 快速琶音，全织体高潮 |
| Ⅴ | 合一 Unity | 84 | 五声和弦铺底，动机回归，余韵渐隐 |

五幕共享同一动机 `宫·商·角·徵 (C→D→E→G)`，由稀疏到密集、由高冷到爆发再回归，构成「万籁同源」的叙事弧。冲突幕刻意引入 `♭Ⅱ(Db)` 与 `Ⅶ(B)` 半音邻居音制造摩擦，合一幕以纯五声和弦消解，完成张力—解决闭环。

## 合成架构 · 集世界顶级算法

- **FM 合成**（John Chowning，数字合成基石）— bell / pluck / lead 音色
- **加法合成**（谐波叠加）— pad 铺底与锯齿 bass
- **Schröder 混响** — FFT 重叠相加卷积，左右声道去相关，宽立体声场
- **母带链** — tanh 软削波 + 峰值归一 + 等功率交叉淡入串联五幕
- **可复现** — 固定种子 PRNG，同一代码永远生成同一首曲
