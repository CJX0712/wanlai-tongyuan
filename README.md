# 《万籁同源》 One Origin of All Sounds

> 世界级原创生成式音乐 · 纯 NumPy 合成 · 零外部依赖 · **作者：晨星**
> 内核：**文明从孤独走向共鸣**

一首由代码生成、可运行、可复现、可验证的原创交响电子作品。五幕递进：

**静谧 → 萌动 → 冲突 → 爆发 → 合一**

本仓库含**两套引擎**，均为同一内核的不同实现：

| 版本 | 引擎 | 调式内核 | 特色 | 状态 |
|------|------|----------|------|------|
| **v2（当前）** | `synth.py` | **D 羽 → D 宫 同主音转调**（F→F#、C→D 解决） | 含**完整中文歌词** + 无词吟唱、完整总谱 `万籁同源_总谱.md`、机器可读 `score.json` | 推荐 |
| v1（原型） | `generate.py` | C 宫五声（宫商角徵羽 = C D E G A） | 单文件赏析页 `index.html`（波形+结构+播放器）、`wanlai_tongyuan.wav`(3:39) | 保留 |

> 设计哲学（作者·晨星）：零重写、集大成、凡更强方案即超越。v2 在 v1 的 FM/卷积混响/软削波母带骨架上，
> 补上了"同主音五声调式转调"这一情感枢纽与完整中文词曲，使"从孤独到合一"刻进音阶本身。

## v2 音乐内核（回答本次创作命题）

| 幕 | 主题 | BPM | 调式 | 意象 |
|----|------|-----|------|------|
| 引子 | 静谧 | 56 | D 羽 | 空、远、独；钟磬 + 无词吟唱 |
| A | 萌动 | 72 | D 羽 | 微光、试探；钢琴 + bass 脉冲 |
| B | 冲突 | 96 | D 羽→离调 | 撕扯、错位；复合节奏 3:4 + 失谐弦乐 |
| C | 爆发 | 132 | 转 D 宫 | 共振、盛大；全编制 + 中文演唱 |
| A' | 合一 | 108→渐慢 | D 宫 | 辽阔、余韵；宽合唱 + 长混响 |
| 尾声 | 同源 | 自由 | D 宫 | 渐隐、永恒 |

**同主音转调的情感密码**：全曲锚定主音 D，前段用 D 羽（小调五声 D F G A C）承载孤独，
后段翻为 D 宫（大调五声 D E F# A B）承载共鸣——同一旋律轮廓，只变两个音（F→F#、C→D），
听感从"叹气"变"绽放"。完整词曲与配器见 [`万籁同源_总谱.md`](万籁同源_总谱.md)。

## 合成架构 · 集世界顶级算法

- **FM 合成**（John Chowning，数字合成基石）→ 钟磬 / 马林巴 / 钢琴
- **加法 / 失谐锯齿合成** → 史诗弦乐 Pad
- **共振峰合成**（频域 Lorentz 共振峰）→ 无词吟唱与占位主唱（啊/喔/呃）
- **Schröder 混响**：FFT 重叠相加卷积，左右声道去相关，宽立体声场
- **母带链**：`tanh` 软削波 + 峰值归一（≤ −0.1 dBFS）+ TPDF 抖动
- **可复现**：固定种子 PRNG，同一代码永远生成同一首曲
